# 💜 Expense Tracker — Full Stack App

A modern, full-stack expense tracking application with authentication, real-time charts, and multi-user data isolation.

![React](https://img.shields.io/badge/React-18-61dafb?logo=react)
![Node](https://img.shields.io/badge/Node.js-Express-339933?logo=node.js)
![MySQL](https://img.shields.io/badge/MySQL-8.0-4479a1?logo=mysql)

---

## ✨ Features

- 🔐 **Secure Authentication** — Register / Login with JWT + bcrypt
- 💸 **Expense Tracking** — Add, edit, delete expenses with categories
- 💰 **Income Management** — Track income sources
- 📊 **Interactive Dashboard** — Stats cards, pie chart, line chart, recent transactions
- 🔒 **Data Isolation** — Users can only access their own data
- 📱 **Responsive Design** — Works on desktop and mobile
- 🎨 **Pastel Gradient UI** — Clean, modern aesthetic

---

## 🛠️ Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | React 18 (Vite), React Router, Axios, Recharts |
| Backend | Node.js, Express.js |
| Database | MySQL 8 |
| Auth | JWT + bcrypt |
| Styling | Custom CSS (pastel gradient) |
